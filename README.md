# 🏃‍♀️ Atherian Move

> Uma aplicação web prática e intuitiva voltada para o acompanhamento de atividades físicas, gerenciamento de rotinas de movimento e hábitos saudáveis.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação prática de **JavaScript moderno (ES6+)**, estruturação de layouts dinâmicos e manipulação interativa do DOM. A aplicação busca oferecer uma experiência fluida para o usuário acompanhar metas de treino, rotinas de exercícios e movimentação diária.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica das seções e formulários de acompanhamento.
* **CSS3:** Estilização visual moderna, suporte a temas e layout responsivo.
* **JavaScript (ES6+):** Lógica interativa, manipulação de eventos e atualização dinâmica da interface.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Acompanhamento de Exercícios:** Registro e visualização de rotinas e séries de atividades.
* **Interatividade em Tempo Real:** Atualização dinâmica de progresso e metas na tela.
* **Design Responsivo:** Interface otimizada para uso em smartphones, tablets e computadores.
